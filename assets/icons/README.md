# Icons

These SVGs are from [skill-icons](https://github.com/LelouchFR/skill-icons) by Baptiste Zahnow, licensed under the MIT License (see [LICENSE](LICENSE)).

Changes: the `-dark` variants were used, and the root `width`/`height` were set to `48` (from `256`) to match the size of the icons served by skillicons.dev. The logos in `hyprland`, `overleaf`, `gnome`, `deepseek` and `kitty` were scaled down (wrapped in a `<g data-logo-scale>` group) so they keep the same padding as the skillicons.dev set.
